Detailed Description

template<typename KeyType, typename ValueType>
class Dictionary< KeyType, ValueType >

Шаблонный класс для реализации словаря (хэш-таблицы) с уникальными ключами.

Template Parameters
KeyTypeТип ключей словаря.
ValueTypeТип значений словаря.

Класс реализует словарь на основе хэш-таблицы. Поддерживает основные операции: добавление, удаление, поиск.
